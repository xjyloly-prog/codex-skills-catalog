# Changelog

## 0.3.0 — 2026-09-19

- Added eight executable semantic exhibit mappings and six native chart primitives
- Added canonical copy bindings, local JSON/CSV contracts, explicit percentage scales and capacity preflight
- Added structurally distinct difficult-page candidates and shared-scale small multiples
- Added actual native chart cache / embedded workbook reconciliation against source-bound contracts
- Blocked stale input/artifact hashes and empty machine reports at the delivery gate
- Added behavioral regressions for missing data, units, rounding, copy drift, wrong workbooks and path escapes
- Kept HTML editors, third-party export engines and automatic installation out of scope
- Expanded the bilingual README with a real chart gallery and tested runtime limits

## 0.2.0 — 2026-08-03

- Added two downloadable, natively editable public demo decks with synthetic data
- Added full-deck previews, per-slide renders, speaker notes, and reproducible demo source
- Reworked the English and Chinese README around real output proof and core differentiation
- Added `production_runtime` to the saved project contract
- Added an optional PPT Master runtime adapter with content locks, security prerequisites, and post-export gates
- Kept PPT Master external: no bundled third-party code, automatic installation, update, or network access

## 0.1.0 — 2026-07-27

Initial public release.

- Three presentation modes and two density modes
- Source-synthesis and hypothesis-led problem-solving routes
- Evidence, hypothesis, chart, storyline, slide, and design-system schemas
- Semantic layout library and four visual directions
- Native-chart-first rendering guidance
- Saved workspace initialization and validation scripts
- PPTX structural inspection
- Machine-readable manual review and final delivery gate
- Neutral default brand plus optional Peng preset
