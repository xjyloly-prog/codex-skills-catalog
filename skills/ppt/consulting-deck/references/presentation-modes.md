# Presentation modes

Choose the mode before planning slides. The mode controls evidence density, layout
grammar, and the acceptable share of conceptual pages.

## Research analytical

Use for industry reports, survey findings, market studies, diligence, and source
material that already contains substantial quantitative exhibits.

The deck should feel like an executive research report rebuilt for presentation:

- use the source's analytical logic and data hierarchy as the primary visual reference;
- inventory every useful source exhibit before writing the storyline;
- make 60–80% of content pages evidence-led;
- preserve sample definitions, periods, units, footnotes, and rounding notes;
- use native editable charts or tables for routine exhibits;
- select chart families from the analytical question, and use complex forms such as
  waterfall, Marimekko, heatmap, matrix, or small multiples only when the extra
  dimension changes the audience's judgment;
- combine a conclusion title, one dominant exhibit, direct annotation, implication,
  and source band on the same page;
- keep covers, section pages, and closing synthesis visually distinctive, but keep
  analytical pages restrained.

For a quantitative source, target at least:

| Deck length | Evidence-led pages | Native chart/table pages |
| --- | ---: | ---: |
| 7–9 slides | 4 | 3 |
| 10–12 slides | 6 | 5 |
| 13–15 slides | 8 | 7 |

Do not reduce a multi-dimensional source exhibit to a hero number or three cards when
the relationships among categories, periods, or segments are material to the claim.

## Executive story

Use for board decisions, client recommendations, strategy choices, and transformation
plans.

- prioritize governing thought, implications, trade-offs, and action;
- use evidence where it changes the decision;
- allow frameworks, comparisons, and roadmaps to carry more of the story;
- keep 35–60% of content pages evidence-led when quantitative material exists;
- use title-as-structure on a small number of decisive pages.

This is the default when the source is mixed or the primary job is a decision rather
than faithful research synthesis.

## Editorial keynote

Use for thought leadership, conference talks, launches, and narrative presentations.

- emphasize pacing, typography, imagery, and memorable transitions;
- keep one idea per slide;
- use large visual metaphors on covers, section pages, and pivotal insights;
- simplify charts only when the omitted detail is not required for the audience's
  judgment;
- move methodology and dense evidence to an appendix.

Do not use this mode for a research-report acceptance test merely because a reference
prompt contains dramatic typography.

## Selection rule

When a user supplies both a visual prompt and a data-rich report:

1. use the report to define analytical page grammar and evidence density;
2. use the visual prompt for cover, section, signature, and closing pages;
3. state the selected mode in `brief.json`;
4. record any deliberate deviation from the mode thresholds in QA.
