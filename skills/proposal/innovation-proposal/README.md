# innovation-proposal — 创新创业大赛项目策划书 Skill

一个 [ZCode](https://zcode.ai) skill：按**大赛官方评审标准**撰写项目策划书 / 商业计划书 / 项目计划书 / 申报书，覆盖大学生创新创业类比赛的绝大多数场景。

> 内置《中国国际大学生创新大赛（2026）评审规则》官方全文（十个赛道组别完整评分表），并适配"挑战杯"、"创青春"、三创赛、服务外包、大创计划（国创）、iCAN 及各类省赛校赛；未收录的赛事可提供当届评分表自动锚定，或按通用五维框架兜底。

## 它能做什么

- **评分表驱动写作**：先拿到所参赛赛事的评分依据，再定制大纲——每个评分要点都有对应章节和证据去回应，篇幅按分值权重分配
- **内置权威评分规则**：《中国国际大学生创新大赛（2026）评审规则》全文（高教主赛道 / 青年红色筑梦之旅 / 职教 / 产业 / 萌芽 × 创意组 / 创业组 / 公益组），含 2026 年新评分点（调研真实性、"团队贡献"、项目与课程/科研训练的联系）的显性写法
- **多赛事适配**：挑战杯（"小挑"）、创青春、三创赛、服务外包、大创计划（研究型申报书结构）、iCAN，及未收录赛事的兜底流程
- **数据真实性红线**：大赛普遍规定材料弄虚作假一票否决，因此强制不编造数据、专利、奖项、合同——缺素材标 `【待补充】` 并汇总清单
- **成稿即交付**：生成带封面、目录、图表编号的 Word 文档，附"评审维度对照表"与"待补充信息清单"

## 适用赛事

| 赛事 | 处理方式 |
|---|---|
| 中国国际大学生创新大赛（原"互联网+"） | 内置 2026 官方评分表全文，逐条锚定 |
| "挑战杯"中国大学生创业计划竞赛（"小挑"） | 典型五维框架 + 写作侧重 |
| "创青春"中国青年创新创业大赛 | 典型框架 + 按创意/初创/成长组别定位 |
| 全国大学生电子商务"三创赛" | 五项积分制框架（创新/创意/创业/演讲/文案） |
| 中国大学生服务外包创新创业大赛 | 产业导向典型框架 |
| 大学生创新创业训练计划（"大创"/国创） | 研究型申报书专用结构 |
| iCAN 及各类省级/校级赛事 | 典型框架；用户提供当届评分表时自动优先 |

## 安装（ZCode）

将本仓库克隆或下载到 ZCode 的用户技能目录，目录名保持 `innovation-proposal`：

```bash
# Linux / macOS
git clone https://github.com/<YOUR-NAME>/innovation-proposal.git ~/.agents/skills/innovation-proposal

# Windows (PowerShell)
git clone https://github.com/<YOUR-NAME>/innovation-proposal.git "$env:USERPROFILE\.agents\skills\innovation-proposal"
```

新开 ZCode 会话即生效。直接说"帮我写大创赛的项目计划书"即可触发，或显式调用 `/innovation-proposal`。

> 想让 skill 只在某工作区生效，可放到 `<工作区>/.agents/skills/innovation-proposal`。

## 使用流程

1. 告诉它：参加哪个赛事、哪个赛道组别、项目一句话简介、已有哪些素材（专利/数据/订单/团队）、有无校方模板
2. 它读取对应评分规则 → 给出定制大纲（章节 + 要点 + 页数分配 + 待补充素材清单）供你确认
3. 确认后逐章撰写 → 生成 Word → 自查 → 交付时附评审维度对照表与待补充信息清单
